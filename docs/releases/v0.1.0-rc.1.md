# Endure v0.1.0-rc.1 prerelease notes

This candidate is an experimental Bittensor testnet-alpha release. Mainnet
serving remains prohibited in code.

- Package/API version: `0.1.0rc1`
- Git tag after live acceptance: `v0.1.0-rc.1`
- Protocol key: `28`
- Bittensor testnet netuid: `504`
- Public API: `https://api.testnet.endure.network`

The candidate bounds Alpha market sampling to the resolution window, settles
permanently unavailable archive timestamps after grace, prevents later joiners
from receiving scores for earlier rounds, and keeps round output embargoed
through the next commit close. It also publishes deterministic calibration
evidence, runtime source/image identity, a signed-feed verification utility,
and an actionable consumer contract.

Known limitations are maintained in
[`../economic-limitations.md`](../economic-limitations.md). In particular,
duplicate/Sybil resistance and independent-validator quorum are unresolved.
Only one public validator endpoint currently exists.

The GitHub prerelease created after live acceptance records the exact source
SHA and immutable validator/miner image digests. Roll back before a key-28
commit window by restoring both key-27 images together. After a key-28 round
opens, stop affected services and preserve evidence; never run mixed protocol
keys or silently reuse the round.
