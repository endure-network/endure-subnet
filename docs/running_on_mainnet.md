# Running Endure on Mainnet

> **Do not run Endure on mainnet.** `v0.1.0` is an experimental testnet alpha,
> not a production or economic-readiness release. Alpha Risk serving is
> code-gated against mainnet pending the testnet soak decision.

The current protocol key is `28` ([version contract](../endure/protocol/version_contract.py)).
Supported development uses Python `>=3.12,<3.13` and Bittensor `>=10.5,<11`.
There is no supported mainnet procedure, image, or operator SLA. Follow the
[testnet runbook](running_on_testnet.md) instead.
