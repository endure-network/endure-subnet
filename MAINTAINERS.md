# Maintainers

Endure's current code owners are:

- [@Apegurus](https://github.com/Apegurus)
- [@empowertz](https://github.com/empowertz)

Every change to `develop`, `staging`, or `main` requires a pull request, one
approval, and CODEOWNER review. Promotion pull requests use merge commits;
feature and fix pull requests are squash-merged into `develop`.

Use GitHub issues for non-sensitive bugs and operator support. Security reports
go privately to `hello@endure.network` under [`SECURITY.md`](SECURITY.md).
Maintainers may stop the testnet soak, reject a protocol cutover, or roll back a
pre-round deployment when health, compatibility, data integrity, or chain
confirmation evidence is incomplete.
